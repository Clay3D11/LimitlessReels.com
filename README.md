# LimitlessReels2.com

A premium real-estate media agency storefront for realtors, teams, brokerages, developers, and luxury listings. This is a separate project; the original `LimitlessReels.com` project remains unchanged.

## Run locally

No dependencies are required.

```sh
npm start
```

Open `http://127.0.0.1:4174`.

## Product features

- Cinematic video-led responsive design
- Playable real-estate portfolio
- Listing package and add-on storefront
- Purchasable pricing catalog adapted from LimitlessStudio
- Category filters, delivery-format selectors, quantities, and live totals
- Persistent mixed cart for fixed-price and custom-quote services
- Property-specific booking request flow
- Mobile navigation and active-section tracking
- FAQ, legal placeholders, accessibility, and reduced-motion support
- Local request storage for preview testing

## Before launch

- Confirm the imported realtor pricing and define rates for the custom-quote package cards and add-ons.
- Connect the booking form to a secure CRM, email provider, or API endpoint.
- Add payment processing only after cancellation, rescheduling, travel, weather, licensing, and refund terms are finalized.
- Replace placeholder legal summaries with counsel-reviewed policies.
- Replace performance claims or testimonials with verified client results as they become available.
- Optimize final video masters for web delivery and configure a CDN for production.
